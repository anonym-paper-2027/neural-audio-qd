# Supplementary listening pages

Static pages with audio examples accompanying the paper. Open `index.html`, or the
hosted copy via GitHub Pages.

- `index.html` — list of all pages
- `favorites_yamnet/` — starred cells of the Prompt-Embed “drum loop” run beside the other search spaces and the class written into the prompt
- `favorites_prompt_only/` — starred cells of the “melodic synth riff” and “ambient pad” runs beside the 1st class written into the prompt
- `maps/` — full archive viewers of the “drum loop” run (YAMNet map, CLAP CVT map)
- `simple/` — one-page maps of the “drum loop” and “ambient pad” runs (fitness threshold, music/other, hover to play)

All clips are 5 s. Map clips are 64 kbps mono MP3; table clips are the original wavs.
